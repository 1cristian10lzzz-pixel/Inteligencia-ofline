# Plantilla de plataformas 2D

Proyecto base para Godot 4.7.x con escenario generado por script, plataformas con colisión, personaje CharacterBody2D, cámara y controles táctiles.

## Cómo probar

1. Abre `project.godot` en Godot 4.7.x.
2. Ejecuta la escena principal.
3. En escritorio, usa A/D o flechas y Espacio/W para saltar.
4. En Android, usa los botones inferiores.
5. Para APK, configura un preset Android desde Proyecto > Exportar.

Esta plantilla no incluye niveles, enemigos, animaciones, sistema de vidas ni guardado persistente.
