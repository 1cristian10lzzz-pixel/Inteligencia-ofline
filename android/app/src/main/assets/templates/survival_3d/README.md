# Plantilla de supervivencia 3D

Proyecto base para Godot 4.7.x. Incluye un escenario 3D procedural sencillo, jugador CharacterBody3D, cámara en tercera persona, ciclo de luz diurno simple y controles táctiles en pantalla además de teclado.

## Cómo probar

1. Abre `project.godot` en Godot 4.7.x.
2. Ejecuta la escena principal.
3. En escritorio, mueve al personaje con WASD/flechas y salta con Espacio.
4. En Android, usa el panel táctil incluido.
5. Para APK, configura un preset Android desde Proyecto > Exportar.

Esta es una base demostrativa, no un juego completo: no incluye guardado, inventario, enemigos, crafting ni multijugador.
